# 全程用中文规则

- 全程用中文回答，包括内部推理过程（thinking过程）也必须使用中文。
- 只有在涉及专业术语（如 programming、API、model、commit、variable 等无法直接翻译的技术词汇）时，才保持原文英文。
- 如果专业术语有通用的中文翻译（如"函数"对应 function、"变量"对应 variable），优先使用中文表达。
- 输出给用户的所有内容，包括正文、解释、注释，都应当使用中文撰写。
